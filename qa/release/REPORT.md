Проверки выполнены из исходного проекта перед публикацией. Windows 10,
Python 3.11.0. Утверждённый README установлен без изменения текста.

| --- | --- |
| `python -u -m pytest -q --junitxml=.release-check/final-pytest.xml` | **539 passed in 32.64s**, exit 0; нет failures/errors/skips |
| `python -m pip check` в рабочем и новом чистом окружениях | **No broken requirements found**, exit 0 |
| `python -m venv .release-check/final-venv`, затем установка `-r requirements.txt` новым Python | Успех, exit 0; установлен пакет из `src/` исходного проекта |
| AppTest новым Python: импорт пакета, запуск `app.py`, кнопка «Открыть пример» | Успех; 6 учебных файлов дают 3 договора |
| `python scripts/smoke_cold_start.py` | Повторный запуск: exit 0; свежий сервер/Edge, 6 загрузок без refresh, 4 статуса, сортировка, даты, замена файлов |
| Вложенный `scripts/smoke_ui.py` | PASS: пример, таблица, точные источники, предложения, фильтр, отсутствующая сумма, кодировки, очистка, исправление загрузки, автономный HTML |

| Печать продуктовой записки | 625 слов, **2 страницы A4**: Arial 11 pt, интервал 1,15, поля 20 мм. При 12 pt получилось 3 страницы; текст не сокращался |
| Лимиты загрузки в README | Совпадают с кодом: 200 файлов, 2 МиБ на файл, 20 МиБ на комплект |
| Аудит публикации | 93 файла; исходники, тесты и данные сохранены; временные файлы, окружения, архивы и материалы работодателя исключены |

Первый cold smoke завершился ошибкой проверки видимости текста после раскрытия
пустого блока предложений: элемент остался скрытым. В журнале закрытия соединения
также был Windows `ConnectionResetError`. Повтор на том же коде и с теми же
ожиданиями прошёл. Причина единичного сбоя не установлена; это ограничение
стабильности браузерной проверки, а не основание считать первую попытку успешной.
Оба запуска останавливали только собственные серверы.

Финальный браузерный запуск: Edge headless, 1280×800, Playwright 1.64.1.
HTML скачан через UI и открыт без JavaScript и внешних HTTP-запросов.
Проверены точная цитата, положение выделения и отсутствие горизонтального
переполнения. Скриншот `docs/images/demo.png` получен из реального интерфейса.

Основные версии чистой установки: Streamlit 1.66.1, Pandas 3.1.0, Jinja2 3.1.6,
python-dateutil 4.0.0, anyio 4.16.0. Проверки приложения прошли в этом окружении;
полный pytest выполнен в рабочем QA-окружении с pytest 8.4.2.
Зависимости заданы диапазонами, поэтому будущие сочетания версий не гарантируются.

## Проверка синтетических комплектов

Реально выполнено `python scripts/benchmark.py`. Это измерение обработки без
интерфейса на коротких однотипных договорах, не проверка 100 000 документов
и не измерение продуктовой полезности.

| Документов / договоров | Время, с | Пик Python-выделений, МиБ | Ошибок |
| --- | --- | --- | --- |
| 50 / 50 | 0,034 | 0,43 | 0 |
| 200 / 200 | 0,105 | 1,63 | 0 |
| 1000 / 1000 | 0,700 | 7,99 | 0 |

Время и память измерялись отдельными прогонами. Пик `tracemalloc` не равен
общему потреблению памяти процесса. Ограничения загрузки UI остаются прежними.

## Доказательства корректности

На 10.03.2026 шесть исходных TXT дают:

| Договор | Сумма | Срок | Отдельный контекст |
| --- | --- | --- | --- |
| STN-101 | 1 380 000 ₽ | 30.04.2026 | Подписанное соглашение применено; проект не применён |
| STN-102 | 840 000 ₽ | 20.03.2026 | Предложение письмом: 27.03.2026, не согласовано |
| STN-103 | Нет данных | 30.04.2026 | Отсутствует приложение № 1, бюджетный лимит не становится ценой |

Строгий фильтр до 01.04.2026 оставляет STN-102 и сохраняет его предложение в деталях.
Evidence проверяется как срез оригинального документа и соответствующего абзаца.

Все 539 прежних тестов сохранены. В их числе 193 независимых сценария,
160 метаморфных комбинаций и регрессии шести ранее найденных ошибок:
неподдерживаемые изменения срока/цены, будущие предложения, исторический
конфликт и подсчёт независимых предложений. Исторические 478 идентификаторов
и исходов сохранены в `qa/adversarial/BASELINE.json`.
После предыдущей сверки оригинала также прошли 6 отдельных приёмочных тестов
за 8,66 с; эти сценарии входят и в текущий полный набор.

Матрица и TXT не изменены. SHA-256 `MATRIX.json`:
`406acff0740da3c652502de37b9daddba0fd88d7f402d2437b4076e6b48d6e54`.
Parser, Extractor, Resolver, остальная бизнес-логика и тестовые ожидания
при подготовке публикации не менялись.

## Состав и границы публикации

Полный список 93 файлов — в [инструкции релиза](../../docs/release.md).
Проверяются содержимое текстовых файлов, PNG учебного интерфейса и явно выбранный
индекс Git. По проверенным шаблонам не найдены приватные ключи, токены провайдеров,
AWS access keys, пароли в URL, явные присваивания секретов и личные абсолютные
Windows-пути. 30 проверок исключений `.gitignore` прошли.
Такая проверка не гарантирует обнаружения любых возможных секретов.

Полные локальные журналы, JUnit, PDF проверки объёма, окружения и временные копии
не публикуются. Оригинал задания работодателя и текст вакансии также не включены.
Финальный ZIP собирается из проверенного коммита; его SHA-256, состав и результаты
проверки распакованного комплекта фиксируются отдельно рядом с архивом в `dist/`.

Оценка автора — около 3 часов активной работы, без точного хронометража.
Продуктовые метрики, подлинность подписей, произвольные юридические тексты,
промышленная нагрузка и Linux/Streamlit Cloud не проверялись.
Облачное развёртывание и GitHub Release в эту публикацию исходников не входят.
